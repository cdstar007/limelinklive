# LIMELINK 競爭定價與網站內容修改草案

日期：2026-10-26。狀態：使用者已確認調整版——只公開官網 8 折，其餘改為專案議價。

## 目的與已知條件

目標客戶是已有直播／RTC 用量、希望降低費用的企業。使用者要求制定競爭策略並修改網站內容。三家供應商的採購成本條件已由使用者提供；此文件及公開網站不披露成本。

## 方案比較與建議

1. 維持現有 95 折入口：保留較多議價空間，但價格吸引力與既有頁面差異不足。
2. 分層定價（已選，依使用者修正）：標準採購官網 8 折；用量承諾與大型企業方案只寫「專案議價」。原先公開更多折扣的提議未獲採用，不能恢復到網站。
3. 全面低價（未採用）：容易理解，但提前用掉議價空間，且不同規模客戶的支援成本差異大。

使用者最終選擇方案 2 的調整版：只公開官網 8 折；用量承諾與企業方案均顯示「專案議價」，不公開較低折扣。公開折扣對應可適用的原廠公開計費項，不保證低於客戶現有合約。最終產品、地區、期間、用量承諾、預付條件、稅費及增值服務以書面報價為準。優惠不自動疊加。

## 修改範圍

這是沿用現有 Nuxt 元件的定價與內容修改，保留現有視覺結構、中英文路由、表單 API 與通知流程。

- 首頁：標題改為「讓現有直播與 RTC 用量，換得更好的採購條件」；主按鈕「評估我的影音成本」；補上先比現有帳單、再評估採購或遷移的說明。
- 頂部促銷列：移除暑期額外 5% 折扣，改為「直播／RTC 採購方案｜官網 8 折起，企業用量另議」與「申請帳單健檢」。
- 報價頁：三層方案同步更新，說明適用對象與議價條件，不承諾永久折扣、固定節省或免費無上限支援。
- 計算器：將標準估算係數由 0.95 改為 0.80，明確標示「公開標價估算」與「標準採購方案估算」。保留既有供應商費率表，本次不宣稱重查所有費率。
- 計算器：可選填目前每月實付 USD，同口徑時顯示與標準估算的差額；如果估算不低於現付，明確顯示沒有估算節省。不能將官網價差當作現有帳單的保證節省。
- 詢價表單：新增現有月支出區間、目前採購狀態、續約時點，均可選填；用量下拉增加「尚不確定」。既有通用表單收集方式可延用。
- SEO：首頁與報價頁標題、描述反映企業影音降本與採購評估。
- 語言：繁體中文與英文同步；頁面預設文字與翻譯資料保持一致。
- 文件：更新經營策略與新增內部毛利／讓價規則，內部採購成本不放進公開內容、public、前端或 runtime config。

## 內部議價原則

以客戶價值與實際合約條件決定價格，不以單一折扣保證勝過所有競爭者。額外讓價必須換得可量化的用量承諾、付款條件或較低交付成本；遷移、客製開發及專屬維運另外報價。既有客戶依有效合約執行。

## 驗證

- 驗證計算器標準價與現付比較的實際數值、零值及無節省情境。
- 執行 Nuxt 正式建置，檢查中英文首頁與報價頁的內容與路由。
- 搜尋過期 95 折／暑期促銷文案及新舊價格矛盾。
- 不在本次修改中觸發正式部署、真實表單或通知。

## 留待執行時處理

由實作判斷使用現有中英文文案機制與元件，避免新增依賴。用量承諾與大型企業的具體門檻由個案報價決定，待有成交與支援成本資料再標準化。
